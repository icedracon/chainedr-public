- 'Fires' is generous: any finding anywhere in the file counts. We do not require the competitor to match the labelled rule class.
- ChainEDR's column uses the corpus label rather than re-running the scanner — the strict run is `python scripts/benchmark_evaluator.py`.
- Some samples fail to compile under the default solc; Slither and Aderyn then count as 'did not fire' rather than failing the run.

\section{Related Work}
\label{sec:related_work}

\textbf{Smart contract static analysis.} Slither~\cite{slither} provides 90+ detectors using an intermediate representation (SlithIR) for data flow analysis. Mythril~\cite{mythril} applies symbolic execution to EVM bytecode. Securify~\cite{securify} verifies compliance and violation patterns against semantic properties. Aderyn performs AST-based analysis in Rust. Semgrep offers generic pattern matching with community Solidity rules. SmartCheck~\cite{smartcheck} uses XML-based pattern matching. These tools do not currently ship dedicated EIP-7702 detector families in the evaluated configurations; our comparison therefore focuses on whether they emit EIP-7702-specific findings rather than on generic Solidity findings.

\textbf{Account abstraction security.} ERC-4337~\cite{erc4337} has been audited by OpenZeppelin and Spearbit, focusing on EntryPoint correctness and bundler safety. ERC-7562~\cite{erc7562} specifies validation scope rules for UserOperation processing. The Pectra upgrade underwent Ethereum Foundation-commissioned security reviews~\cite{pectra_audit}. However, these efforts focus on the account abstraction \textit{infrastructure} (EntryPoint, bundler), not on the impact of delegation on \textit{existing} Solidity code---which is the gap ChainEDR addresses.

\textbf{Delegation-specific analysis.} To our knowledge, prior mainstream static analyzers have not systematically modeled how EIP-7702 delegation breaks existing Solidity security assumptions. The closest related work is ERC-7562's bundler-side validation rules, which operate at \textit{runtime} on UserOperations, not at \textit{compile time} on source code. ChainEDR provides static, pre-deployment detection of delegation-specific vulnerabilities and implements ERC-7562 validation scope checks as compile-time rules (AA7562-001 through AA7562-009).
